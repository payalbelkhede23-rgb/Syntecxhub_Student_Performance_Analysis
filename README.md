# Student Performance Analysis

## Project Overview

This project analyzes student performance using Microsoft Excel. It explores exam scores and their relationships with study hours, attendance, class, and motivation level.

**Dataset note:** This project uses synthetic educational data for practice and demonstration. It does not represent real student records.

## Objectives

* Clean the dataset by handling missing values and duplicate records.
* Calculate overall student performance metrics.
* Compare average exam scores across classes.
* Analyze study hours, attendance, and motivation levels.
* Present findings using charts and tables.
* Recommend ways to support student learning.

## Tools Used

* Microsoft Excel
* Excel formulas: `AVERAGE`, `AVERAGEIF`, `AVERAGEIFS`, and `COUNTIF`
* Column charts, a pie chart, and data tables

## Analysis Performed

* Total students analyzed: 975
* Average exam score: 41.53
* Average attendance: 82.58%
* Average study hours per week: 5.24

## Key Findings

* Class B has the highest average exam score at 42.28.
* Students studying 9–12 hours per week have the highest average score at 47.93.
* Students with attendance of 90–100% have the highest average score at 42.61.
* Students with high motivation have the highest average score at 44.32.

## Recommendations

* Encourage regular study schedules.
* Monitor attendance and support students with frequent absences.
* Use engaging lessons and positive feedback to support motivation.
* Provide additional practice and academic support where needed.

## Project Files

* `Student_Performance_Cleaned.xlsx` — cleaned dataset, analysis tables, charts, findings, and recommendations.

## Conclusion

This project demonstrates how Excel can be used to clean data, analyze student performance, visualize patterns, and communicate insights. The findings describe the synthetic dataset and should not be interpreted as conclusions about real students.
